# Чек-листы СМП

Чек-лист отвечает на вопрос что проверить, без подробных тестовых данных и шагов

## 1. Классы верхнего уровня

| Сервис | Проверить |
|---|---|
| Gateway | валидные/невалидные запросы, проксирование, rate limit, tracing |
| Switch | известный/неизвестный BIN, маршрутизация, откат при сбое публикации |
| Bin Lookup | известный/неизвестный BIN, timeout, fallback |
| Terminal Simulator | допустимые/недопустимые сценарии и количество транзакций |
| Merchant Simulator | сценарии, MCC, комиссия |
| Transaction Logger | запись, поиск, фильтры, пагинация, дубликаты, real-time |
| Notification Service | события карт, некорректные события, RabbitMQ |
| Web Dashboard | отображение данных и восстановление real-time соединения |

## 2. Дымовое тестирование

### Инфраструктура
- [ ] Система запускается.
- [ ] Все контейнеры healthy.
- [ ] PostgreSQL доступен.
- [ ] RabbitMQ доступен.
- [ ] В логах старта нет критических ошибок.

### Сервисы
- [ ] Gateway health-check.
- [ ] Card Management health-check.
- [ ] Switch health-check.
- [ ] Authorization health-check.
- [ ] Terminal Simulator доступен.
- [ ] Merchant Simulator доступен.
- [ ] Transaction Logger доступен.
- [ ] Bin Lookup доступен.
- [ ] Notification Service доступен.
- [ ] Dashboard открывается.

### Базовый сценарий
- [ ] Создаются тестовые карты.
- [ ] Карта находится по PAN.
- [ ] Bin Lookup возвращает данные.
- [ ] Транзакция проходит через Gateway.

- [ ] Terminal Simulator запускает пакет транзакций.
- [ ] Dashboard показывает данные.
- [ ] `scripts/smoke-test.sh` завершается успешно.

## 3. Критический путь

### Основной поток
- [ ] Покупка проходит через Gateway → Switch → Authorization → Card Management → Logger → Dashboard.
- [ ] Ответ содержит решение, код, RRN и authCode.
- [ ] После APPROVED уменьшается баланс.
- [ ] Учитываются дневной и месячный лимиты.
- [ ] После DECLINED баланс и лимиты не меняются.

### Отказы
- [ ] Карта отсутствует.
- [ ] Неизвестный BIN.
- [ ] INACTIVE.
- [ ] BLOCKED.
- [ ] Истёкший срок.
- [ ] Превышен дневной лимит.
- [ ] Превышен месячный лимит.
- [ ] Недостаточный баланс.
- [ ] Проверяется порядок правил из ТЗ.
- [ ] Код и причина отказа корректны.
- [ ] Отказ записывается в Logger.

### Надёжность
- [ ] RabbitMQ и outbox работают штатно.
- [ ] При неподтверждённой публикации резерв откатывается.
- [ ] Повторная доставка не создаёт дубликат.
- [ ] Недоступность Authorization обрабатывается корректно.
- [ ] Недоступность Card Management обрабатывается корректно.
- [ ] Недоступность Bin Lookup не ломает решение.
- [ ] События карт доходят до Notification Service.
- [ ] При недоступном RabbitMQ событие сохраняется до исчерпания retry.
- [ ] Параллельные резервы не дают отрицательный баланс.

### Gateway / периферия
- [ ] Gateway отклоняет некорректные запросы.
- [ ] Rate limit работает.
- [ ] Ошибка нижестоящего сервиса возвращается корректно.
- [ ] Поиск транзакций и пагинация работают.
- [ ] Dashboard соответствует данным Logger.
- [ ] CRUD карт доступен.
- [ ] Удалённая карта не участвует в транзакциях.
- [ ] Сценарии обоих симуляторов работают.
- [ ] Dashboard обновляется в реальном времени.
- [ ] Dashboard восстанавливает соединение.
